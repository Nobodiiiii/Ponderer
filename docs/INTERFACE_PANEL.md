# 显示界面步骤

`interface_panel` 在当前结构场景中显示一个界面教程面板，不创建新的场景段。
外框复用 Ponder `renderSpeechBox` 所用的 Catnip `BoxElement`、配色和箭头纹理，与 `show_controls` 使用相同风格。`BoxElement.withBorderOffset(0)` 取消默认内边距，背景覆盖界面显示矩形，边框直接贴在外侧。
界面按原窗口布局离屏绘制，只将 GUI 区域等比例缩放到面板中；世界场景继续保留。

编辑器入口：添加步骤 → 叙事 → 显示界面。面板页面包含位置、方向、偏移与缩放、显示面板背景、阻塞后续步骤、框选显示范围以及子步骤列表。
点击子步骤进入原有编辑器；子步骤可以添加、排序、删除，第一条打开界面的步骤保留并允许编辑。
子步骤保存到面板草稿，保存面板才写入场景；放弃面板会一起放弃子步骤修改。
界面捕获、坐标拾取、槽位编辑完成后返回相应的子步骤编辑器。
框选页面继承本模组 `AbstractDeclarativeScreen`（Catnip `ConfigScreen`），沿用界面缩放、背景、面包屑和 Catnip 按钮。

```json
{
  "type": "interface_panel",
  "point": [2.5, 1.5, 2.5],
  "direction": "down",
  "panelTransform": [0, 0, 0.5],
  "panelBackground": true,
  "panelBlocking": true,
  "steps": [
    { "type": "show_interface", "block": "minecraft:crafting_table" },
    { "type": "idle", "duration": 20 },
    { "type": "text", "text": "在这里放入材料", "point": [0, 0], "duration": 60 },
    { "type": "idle", "duration": 60 }
  ]
}
```

- `point` 是世界锚点，`direction` 沿用操作提示框的指向。面板会避开窗口边界。
- `panelTransform` 为 `[X 偏移, Y 偏移, 缩放]`，默认 `[0, 0, 0.5]`。编辑器复用 XYZ 三联输入框，内部灰字依次为“X 偏移”“Y 偏移”“缩放”。偏移使用屏幕 GUI 像素，正值分别向右、向下，作用于整个面板的位置；缩放相对于原界面 GUI 像素，必须为有限正数。宽高按原界面或选区比例计算，超出窗口时进一步等比缩小，偏移后仍限制在窗口内。
- `panelBackground` 默认 `true`，关闭“显示面板背景”后隐藏外层操作提示框的背景、边框和指向箭头，仅保留原界面内容。原界面的纹理背景仍正常显示；面板渲染会排除原生容器的全屏半透明暗幕。
- `panelBlocking` 默认 `true`，开启“阻塞后续步骤”时等待全部子步骤与标注结束后继续主时间轴，兼容未填写该字段的旧场景。设为 `false` 时，界面教程与主场景后续步骤并行执行，内部等待和操作仍按顺序推进，结束后自动关闭界面；交互目标只暂停该界面教程。进度条和跳转包含教程的完整时长。
- 默认显示完整 GUI，不再自动裁切玩家物品栏。点击“框选显示范围”会打开第一条子步骤对应的原界面：左键拖动建立选区，拖动边或角调整，按住 Ctrl 以中心为基准同步调整对侧边；右键拖动框内可平移。点击“完成”应用到面板草稿，“取消”或 Esc 放弃本次框选，“恢复完整界面”清除裁切。
- 在框选页中键点击可见区域，会按原界面 GUI 像素的非零透明度，沿上下左右查找与点击位置连通的区域，并将选区设为其最小包围矩形。Ctrl＋中键追加区域，最终选区为全部所选区域的整体最小包围矩形；没有自定义选区时，首次 Ctrl＋中键建立选区。普通中键重新单选，“恢复完整界面”清除追加状态。不同颜色仍可连通，透明间隙会分隔连通区域；点击透明处保留原选区并提示。只在中键点击时读取离屏像素，排除原生全屏暗幕、悬浮提示及编辑器遮罩，不向原界面发送点击事件。选中后仍可拖动微调；第三方自行绘制的全屏背景可能将多个区域连在一起。
- 可选 `panelCrop` 保存归一化的 `[x, y, width, height]`，范围在完整界面显示边界内，缺省表示完整界面。例如 `[0, 0, 1, 0.42]` 只保留顶部 42%。相对坐标用于适应窗口与 GUI 缩放变化；边界按当前界面像素取整。裁切只改变显示和输入区域，不删除菜单槽位，不改变脚本槽位编号或原界面坐标。选区外槽位不提供鼠标、JEI 投放和查询目标。
- 显示边界与容器的槽位坐标矩形分别计算：包含外置可见控件、Create 声明的额外显示区，并补齐 Create 邮箱/蛙港的独立标题栏及物品栏底部。邮箱声明 220×190，但上方另绘制 24 像素标题栏，下方另绘制 8 像素物品栏底边，右侧还有模型显示区；框选页和播放统一使用扩展后的完整范围。
- 整合包和模组可通过客户端资源 `assets/<命名空间>/ponderer/interface_exclusions/*.json` 控制外来控件排除，内置 JEI、FTB 使用同一逻辑；格式、覆盖及自身界面保护见 [控件排除规则](INTERFACE_EXCLUSIONS.md)。
- `steps` 必须以 `show_interface` 开头。面板内部的文字和操作提示使用原始 GUI 矩形的归一化坐标，经过与界面内容相同的裁切、缩放和平移映射到屏幕；裁切和外置控件不会改变附着目标，坐标拾取与播放使用同一范围。主场景后续步骤继续使用主场景原有的坐标模式。
- 编辑器可添加等待、文字、操作提示、槽位修改、点击、声音。JSON 同时支持共享文字以及运行库的 `set_interface_*`、`interface_action`、`await_interface`。
- 子步骤顺序执行，是否阻塞主时间轴由 `panelBlocking` 决定。内部标注和数据动画结束后立即销毁界面会话，没有额外的末尾停留字段；需要停留时添加 `idle` 子步骤。面板上方不显示“试一试”；独立界面仍保留该按钮，试操作暂停主时间轴。
- 当前仍只允许一个活动界面会话，不支持面板套面板或在子步骤中修改世界。后续步骤打开另一个界面时，原有非阻塞教程停止并清理自身标注，不会继续操作或关闭新界面。原有独立界面场景继续使用。
- JSON_LIB / JAVA_LIB 沿用场景模型并保留子步骤；纯原生 Ponder / PonderJS 没有对应的界面面板 API。

## 验证范围

代码改动使用 Common、NeoForge、Fabric 及两端运行库的 scoped build，运行已有 Common JUnit；不添加测试或自动界面操作。
阻塞开关还需手动检查：新建与旧场景默认开启、保存回显、框选或子步骤编辑返回后保留开关、关闭后主场景与教程同时推进、教程结束关闭、被后续界面替换时停止旧操作、播放与拖动进度条重建一致，以及交互目标只等待自身教程。
游戏内仍需手动检查：结构与面板同时显示、偏移与缩放默认值及灰字、正负偏移和窗口边界、外框无内边距、子步骤结束即关闭、背景开关保存与回显、关闭背景后的透明区域、缩放后的点击/拖拽/JEI 槽位目标、面板不显示“试一试”而独立界面仍可试操作、重播、不同 GUI 缩放、界面捕获返回、子步骤保存与放弃，以及手动框选、中键选取连通区域、Ctrl＋中键追加多选及普通中键替换、透明处点击保留选区、Ctrl 对称调整、框内右键平移、恢复完整界面、框选完成与取消。邮箱需确认顶部标题、物品栏底边和右侧模型完整显示，裁切及缩放后的文本附着点仍对应原始 GUI 位置，Catnip 页面关闭后界面缩放正常恢复。
动态 tooltip 和未声明边界的第三方自绘内容仍会受面板裁剪边界限制。
